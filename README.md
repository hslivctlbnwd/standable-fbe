## 🤖 Overview

Standable uses neural network pose estimation from the headset and two controllers to infer hip and leg positions for full body tracking without any additional hardware.

Whether you're a newcomer or a veteran, Standable: Full Body Estimation provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **No Extra Hardware** | Full body tracking with only HMD and two controllers |
| **Neural Pose Net** | Deep learning model estimating hip and leg positions in real time |
| **SteamVR Output** | Outputs hip, knee, and foot virtual trackers to SteamVR |
| **Low Latency** | Inference runs locally for minimal added tracking delay |
